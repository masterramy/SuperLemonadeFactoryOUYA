## Full description
**Super Limeade Factory** is a retro puzzle-platformer built around switching between Andre and Liselot as they make their way through a sprawling soft-drink factory. Each character has different movement abilities, so progress depends on positioning, timing, exploration, and using both characters together.

This Android edition restores and modernizes the GPLv3-released OUYA source for current Android devices, including touch controls and modern display handling while preserving the original game's pixel-art character and level design.

Super Limeade Factory is an **independent Android restoration/modification published by Ramy Baheeg**. It is based on the original **Super Lemonade Factory** by **Shane Brouwer / Initials Video Games**. This Android edition is **not produced, sponsored, or endorsed by Shane Brouwer or Initials Video Games**.
